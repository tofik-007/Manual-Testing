# Bug Report: BUG-001

**Title:** First Name field on checkout accepts invalid input with no validation

**Severity:** Medium
**Priority:** Low

**Environment:**
- URL: https://www.saucedemo.com
- Browser: Chrome
- Account used: standard_user

**Steps to Reproduce:**
1. Add an item to cart and proceed to checkout step one
2. Enter numbers or special characters into the First Name field
3. Fill remaining fields with valid data and click Continue

**Expected Result:**
Field should reject non-name input (numbers, special characters) or at least flag it, consistent with basic form validation practice.

**Actual Result:**
Any input is accepted with no client- or server-side validation.

**Frequency:** Always

**Notes:**
Related to BUG-002 and BUG-003 — the entire checkout form appears to lack input validation across all three fields. Recommend a broader validation review rather than fixing fields individually.
