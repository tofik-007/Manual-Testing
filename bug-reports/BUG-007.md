# Bug Report: BUG-007

**Title:** Cart contents persist across logout and login as a different user

**Severity:** High
**Priority:** High

**Environment:**
- URL: https://www.saucedemo.com
- Browser: Chrome
- Accounts used: multiple (e.g., standard_user then a second account)

**Steps to Reproduce:**
1. Log in as User A, add one or more items to cart
2. Log out
3. Log in as User B
4. Observe cart badge and cart page contents

**Expected Result:**
Cart is empty for the new session/user; no carryover from the previous user's session.

**Actual Result:**
Cart still shows item(s) added by the previous user.

**Frequency:** Always, confirmed across multiple account pairs.

**Notes:**
This is a session-isolation issue, not just a UI quirk. In a real production app, this pattern (one user's cart/data persisting into another user's session) would be treated as a data integrity and privacy concern, not a cosmetic bug. Recommend treating as release-blocking. Follow-up needed: confirm whether this also survives a hard browser refresh, not just logout/login.
