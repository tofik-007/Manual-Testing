# Bug Report: BUG-009

**Title:** Navigation bar is misaligned and cart icon overlaps the sort dropdown when logged in as visual_user

**Severity:** Medium
**Priority:** Low

**Environment:**
- URL: https://www.saucedemo.com
- Browser: Chrome
- Account used: visual_user

**Steps to Reproduce:**
1. Log in as visual_user / secret_sauce
2. Navigate to the Products page
3. Observe the navigation bar and cart icon position relative to the sort dropdown

**Expected Result:**
Navigation bar renders level/aligned; cart icon is in its standard position, not overlapping other UI elements.

**Actual Result:**
Navigation bar appears tilted; cart icon is shifted and overlaps the sort dropdown's position.

**Frequency:** Always, confirmed on repeat login/page reload.

**Notes:**
Related to BUG-008 — both are visual/CSS defects under visual_user. Severity may need to be raised to High if the overlap actually blocks clicking the Cart icon or Sort dropdown (not yet confirmed) — currently treated as cosmetic.
