# Bug Report: BUG-006

**Title:** Sort dropdown has no effect on product order when logged in as problem_user

**Severity:** Medium
**Priority:** Medium

**Environment:**
- URL: https://www.saucedemo.com
- Browser: Chrome
- Account used: problem_user

**Steps to Reproduce:**
1. Log in as problem_user / secret_sauce
2. On the Products page, select any option from the sort dropdown (Name A-Z, Name Z-A, Price low-high, Price high-low)
3. Observe product list order

**Expected Result:**
Product order updates to match the selected sort option.

**Actual Result:**
Product order remains unchanged regardless of selection.

**Frequency:** Always, across all four sort options tested.

**Notes:**
This is the third functional issue found under problem_user (see BUG-004, BUG-005). Recommend re-testing this account's core interactions broadly rather than treating each as isolated — suggests a shared root cause (e.g., event handlers not bound correctly for this account/session state).
