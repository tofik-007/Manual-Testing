# Bug Report: BUG-002

**Title:** Last Name field on checkout accepts invalid input with no validation

**Severity:** Medium
**Priority:** Low

**Environment:**
- URL: https://www.saucedemo.com
- Browser: Chrome
- Account used: standard_user

**Steps to Reproduce:**
1. Add an item to cart and proceed to checkout step one
2. Enter numbers or special characters into the Last Name field
3. Fill remaining fields with valid data and click Continue

**Expected Result:**
Field should reject non-name input or flag it.

**Actual Result:**
Any input is accepted with no validation.

**Frequency:** Always

**Notes:**
Related to BUG-001 and BUG-003 — systemic lack of validation across the checkout form. Recommend a broader validation review rather than fixing fields individually.
