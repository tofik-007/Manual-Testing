# Bug Report: BUG-003

**Title:** Zip/Postal Code field on checkout accepts invalid input with no format validation

**Severity:** Medium
**Priority:** Low

**Environment:**
- URL: https://www.saucedemo.com
- Browser: Chrome
- Account used: standard_user

**Steps to Reproduce:**
1. Add an item to cart and proceed to checkout step one
2. Enter letters or special characters into the Zip/Postal Code field
3. Fill remaining fields with valid data and click Continue

**Expected Result:**
Field should enforce a reasonable postal code format or flag invalid input.

**Actual Result:**
Any input (letters, special characters) is accepted with no format validation.

**Frequency:** Always

**Notes:**
Related to BUG-001 and BUG-002 — systemic lack of validation across the checkout form. Recommend a broader validation review rather than fixing fields individually.
