# Bug Report: BUG-011

**Title:** Checkout flow cannot be completed when logged in as error_user

**Severity:** High
**Priority:** High

**Environment:**
- URL: https://www.saucedemo.com
- Browser: Chrome
- Account used: error_user

**Steps to Reproduce:**
1. Log in as error_user / secret_sauce
2. Add item(s) to cart
3. Proceed to checkout and attempt to complete the flow (enter info, continue, finish)

**Expected Result:**
Checkout completes normally and displays order confirmation, consistent with standard_user behavior.

**Actual Result:**
Checkout flow fails and cannot be completed.

**Frequency:** Always

**Notes:**
This blocks the core purchase flow entirely for this account, similar in impact to BUG-004 (Add to Cart failure under problem_user) and BUG-007 (cross-user cart persistence). Recommend treating as release-blocking if this account represents a real user segment.
